# 📚 Harini's Book Store & Portfolio Website

This project is a multi-page web application that combines a personal portfolio with an online bookstore. It is built using HTML, CSS, and JavaScript without any backend, using browser storage to manage data.

## 🚀 Features

- 🧑‍💻 Personal Portfolio showcasing skills, projects, and author journey
- 🛒 Add to Cart functionality using localStorage
- ➕ Increase/decrease product quantity
- 💳 Checkout form with order placement
- 📦 Order tracking using email
- 📱 Fully responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage (for data handling)

## 📂 Pages Included

- Home (Portfolio)
- Store (Book listing)
- Cart
- Checkout
- Order Tracking

## ⚙️ How It Works

- Products are added to the cart and stored in the browser using localStorage
- Users can modify quantities and proceed to checkout
- Order details are saved locally and can be retrieved in the tracking page using email

## 🎯 Purpose

This project was built to practice frontend development concepts and simulate a real-world e-commerce workflow without using a backend.
